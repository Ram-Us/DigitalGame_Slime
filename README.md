**🚀 プロジェクトのセットアップ & 実行手順**
リポジトリのクローン

Bash


git clone https://github.com/Ram-Us/DigitalGame_Slime.git
Unity Hub で開く

Unity Hub を起動し、Add（追加）からクローンしたフォルダを選択します。

該当する Unity バージョンでプロジェクトを開きます。

シーンの読み込みと実行

Assets/Scenes/ 配下にあるメインシーン（Main.unity や SampleScene.unity など）を開き、Editor 上で Play（再生）ボタンを押して実行してください。
