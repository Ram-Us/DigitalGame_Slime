**工夫した点**

①スライムの変形ギミック

  本作で最も力を入れたのは、スライムが縦長・横長に変形するギミックです。
  Blenderでスライムの3Dモデルを作成し、縦長・横長の形状をシェイプキーとして登録してUnityへ取り込みました。
  Unityでは、プレイヤーの入力に応じてAnimator Controllerの状態を切り替え、アニメーションからBlendShapeの値を変化させています。
　また、変形後の見た目に当たり判定を追従させるため、Colliderの中心位置も変形状態に応じて更新しています。
  変形前と変形後のCollider CenterをLerp関数で補間し、当たり判定の位置が滑らかに切り替わるようにしました。
  
②プレイ前後の印象を高める画面演出

  タイトル画面とスコア画面では、静止したUIを表示するだけで終わらせず、カメラアニメーションを取り入れました。
  特にタイトル画面では、タイトルロゴに動きを付けて表示し、カラフルなスライムたちを行進させることで、本作の明るい世界観を最初の画面から伝え、プレイ前の期待感を高めることを意識しました。スコア画面にもカメラワークを加え、結果を確認する場面までゲームの演出が途切れないようにしています。
  
**プロジェクトのセットアップ & 実行手順**
  リポジトリのクローン
  
    Bash
    
    
      git clone https://github.com/Ram-Us/DigitalGame_Slime.git
    Unity Hub で開く
    
    Unity Hub を起動し、Add（追加）からクローンしたフォルダを選択します。
    
    該当する Unity バージョンでプロジェクトを開きます。
    
    シーンの読み込みと実行
    
    Assets/Scenes/ 配下にあるメインシーン（Main.unity や SampleScene.unity など）を開き、Editor 上で Play（再生）ボタンを押して実行してください。
